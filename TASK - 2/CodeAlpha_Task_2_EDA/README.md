# CodeAlpha Task 2 — Exploratory Data Analysis (EDA)

This project completes **Task 2: Exploratory Data Analysis (EDA)** from the CodeAlpha Data Analytics task list.

## What it does
- Loads `data/books_dataset.csv`
- Reviews dataset dimensions, column names, data types, and descriptive statistics
- Checks missing values, duplicate rows, and duplicate product URLs
- Detects potential price outliers using the 1.5 × IQR rule
- Checks the relationship between book price and rating when enough valid data exists
- Exports a readable EDA report and a data-quality CSV

## Setup (Windows PowerShell)
Open this folder in VS Code, then run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If activation is blocked in PowerShell, run this in the current terminal and try activation again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Run Task 2
From the project root:

```powershell
python src/eda_analysis.py
```

Outputs:
- `outputs/eda_summary.txt`
- `outputs/data_quality.csv`

## Dataset
The included CSV is a starter sample from the practice site Books to Scrape. For analysis of your actual Task 1 result, replace `data/books_dataset.csv` with the `books_dataset.csv` generated by your scraper. Keep the same column names if possible.

## Meaningful questions investigated
1. What are the typical and range of book prices?
2. Which books have the highest and lowest prices?
3. How are ratings distributed?
4. Are price and rating associated in this sample?
5. Are there missing values, duplicates, or potentially unusual prices?

## Limitations
This is a small catalogue sample. Findings describe only this sample and should not be generalized to all books. Correlation does not imply causation.
