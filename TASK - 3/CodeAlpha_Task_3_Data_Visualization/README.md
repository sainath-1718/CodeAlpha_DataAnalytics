# CodeAlpha Task 3 — Data Visualization

This project covers **Task 3: Data Visualization** from the CodeAlpha Data Analytics task list.

## Features
- Visualizes book price distribution with a histogram
- Shows the number of books by star rating
- Compares book price and rating using a scatter plot
- Visualizes availability counts when the column is present
- Saves publication-ready PNG charts in `outputs/charts/`

## Setup (Windows PowerShell)
Open this folder in VS Code and run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks activation, use this command in the current terminal and retry:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Run Task 3
From the project root:

```powershell
python src/visualize_books.py
```

Charts are saved to `outputs/charts/`.

## Dataset
A starter CSV is included so the script can run immediately. For your internship submission, replace `data/books_dataset.csv` with the actual `books_dataset.csv` generated by your Task 1 scraper (40 records from your successful run). Keep the column names the same.

## Interpretation guidance
- Histogram: shows how prices are distributed in the selected sample.
- Rating bar chart: compares counts for each star rating.
- Scatter plot: shows whether price and rating appear associated in the sample.
- Availability chart: compares listing availability labels if that column is present.

These charts describe the provided sample only. A visible association does not prove causation.
