CODEALPHA TASK 1 — QUICK START (Windows)

1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Create and activate a virtual environment:
   python -m venv .venv
   .venv\Scripts\activate
5. Install packages:
   python -m pip install -r requirements.txt
6. Run the scraper:
   python src/scrape_books.py --pages 2
7. Check the generated file:
   data/books_dataset.csv
8. Read README.md and reports/project_report.md.
9. Take screenshots of the terminal output and CSV rows after your own successful run.
10. Upload the folder to GitHub as CodeAlpha_Web_Scraping_Books.
