# Project Report: Books and Prices Web Scraping

## 1. Project Title
**CodeAlpha Data Analytics Internship — Task 1: Web Scraping**

## 2. Abstract
This project demonstrates web scraping using Python. The script retrieves book catalogue pages from Books to Scrape, extracts book titles, listed prices, star ratings, availability text, and product URLs, and stores the structured data in a CSV file. Requests is used for HTTP communication, BeautifulSoup for HTML parsing, and pandas for dataset creation and quality checks.

## 3. Objective
- Learn how website HTML is structured.
- Automatically collect selected fields from a public practice website.
- Create a structured CSV dataset for future data analysis.
- Validate the output for missing values and duplicate product links.

## 4. Data Source
Website: https://books.toscrape.com/  
Books to Scrape is a practice website designed for learning scraping. The scraper targets catalogue pages and does not attempt to bypass access controls.

## 5. Tools and Technologies
- Python 3.10+
- Requests — retrieve web pages using HTTP.
- BeautifulSoup — parse HTML and select elements.
- pandas — organize data and export CSV.
- CSV — store the extracted dataset in a portable tabular format.

## 6. Dataset Description
| Field | Type | Meaning |
|---|---|---|
| Book_Name | Text | Title of the book |
| Price_GBP | Numeric | Listed price in GBP |
| Rating_Stars | Integer | Star rating from 1 to 5 |
| Availability | Text | Availability text displayed on the catalogue |
| Product_URL | URL/Text | Link to the book detail page |

## 7. Methodology
1. Create an HTTP session and send a GET request to the catalogue.
2. Check the HTTP response for errors.
3. Parse the response HTML with BeautifulSoup.
4. Select each book card and extract the required fields.
5. Convert the price string to a numeric value and the star-rating class to an integer.
6. Combine records into a pandas DataFrame.
7. Remove duplicate product URLs and export the data to CSV.
8. Print record count, missing-value counts, duplicate count, and price statistics.

## 8. Output Files

**Data integrity note:** The included sample CSV is an example dataset, not a fresh scrape performed during packaging. Use the script to create a current live dataset and report its actual output.

## 9. Results and Validation
When executed successfully, the script reports:
- Number of scraped records
- Column names
- Missing values per column
- Duplicate product URLs
- Minimum, maximum, and average listed price

Record counts and summary statistics should be copied from the user's actual run. They are intentionally not fabricated in this report.

## 10. Limitations
- Results depend on the website's current HTML structure and availability.
- The example script collects catalogue listing fields only; it does not follow pagination automatically beyond the page count supplied by the user.
- Prices are in GBP as displayed by the source and are not converted to INR.
- The sample dataset is for demonstration and may not reflect the live site at submission time.
